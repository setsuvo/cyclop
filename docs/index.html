The MacBook notch as a working tool

Cyclop is a free, open-source notch app for macOS. Invisible at rest; on hover it unfolds into a panel with a player, a file shelf, clipboard history, snippets, your next meeting and an offline translator.

What Cyclop puts in the notch

Nine content tabs. Background work stops when its tab is disabled in Settings.

Music

Artwork, track, artist and a scrubber that actually seeks. The source is anything macOS itself can see: Apple Music, Spotify, or a video in a browser tab. Nothing to configure in the browser.

Shelf

Drag files into the notch and they wait there. Drag a card out and the file goes wherever it is dropped. ⌘-click selects several and drags them as a group. Opt-in clipboard-image saving can put any copied PNG or TIFF here too — including one copied on an iPhone. Upgrades from older versions reset it to off once.

Clipboard

The last 40 copies. A click puts an entry back on the clipboard.

Snippets

A hand-kept list of what you are tired of retyping: an address, a phone number, an email. The same list is a plain JSON file you can edit in any editor.

Calendar

The next meeting a week ahead, how long until it starts, and a button that joins the call — Zoom, Meet, Teams and others. Meetings that overlap each get their own join button.

Translate

Type on the left, the translation appears on the right — offline, using macOS's own translation, with no service and no account. English to Russian and back; the direction is taken from the script the text is written in.

Currency

Convert in either direction using public daily rates. With this tab enabled, rates are fetched over HTTPS at startup and refreshed hourly.

Teleprompter

A script that scrolls under the camera at a speed you set. The notch is the one place on the screen a teleprompter belongs: the eyes stay on the lens instead of travelling to a window below it.

Notes

Scratch space. Hovering lands with the caret ready; blank notes sweep themselves out.

How Cyclop is different

The notch category is crowded. These are the things Cyclop is measured on, all of them checkable in the source.

Zero dependenciesNothing but Swift, SwiftUI and AppKit. No package manager, no vendored frameworks. The whole thing stays under 10,000 source lines and can be audited directly.
No permission at launchCalendar access is requested only by an explicit button in that tab. The normal Now Playing path needs no Automation or Accessibility; its fallback may require those for Apple Music, Spotify or media keys. Screen Recording is not used.
Any media sourceNow Playing is read from macOS itself, so a video in a browser tab works exactly like a music player — no browser extension, no per-app connector.
Offline translationTranslation runs on the device through macOS's own framework. No API key, no account, nothing leaves the machine.
Nothing collectedNo telemetry, analytics or crash reporting. The two outbound paths are public currency data and, only on the Spotify fallback, album artwork; neither sends clipboard, file, note or calendar content.
Actually small4.2 MB on disk, around 40 MB of memory, 0.0 % CPU while the panel is closed.

Install

  1. Download the latest .dmg from the releases page, open it and drag Cyclop into Applications.
  2. Open it normally. Official images are signed with a Developer ID and notarised by Apple, so no Gatekeeper workaround is expected.
  3. Do not bypass an unexpected verification failure. Delete the file, download the current image again from the official releases page, and report it if the failure repeats.
  4. Or build it yourself — the whole thing is one command, and no Xcode project is involved:
git clone https://github.com/akalikbergenov/cyclop.git
cd cyclop && ./Scripts/bundle.sh release

Questions

Does Cyclop work on a MacBook without a notch?

Yes. On a Mac without a physical cutout Cyclop draws a synthetic notch exactly as tall as the menu bar and behaves the same way. It works on external displays too.

What permissions does Cyclop need?

None in normal use until you explicitly request Calendar access from its explanation screen. Cyclop does not use Screen Recording. If the normal Now Playing path stops working, the fallback can require Automation for Apple Music or Spotify and Accessibility for media keys.

*A file placed on the shelf from Downloads, Documents or the Desktop can also produce a macOS file-access prompt, only when the shelf is opened.

Is Cyclop free? Is there a paid version?

Free, MIT-licensed, and there is no paid tier. No subscription, no ads, no accounts, and nothing is collected.

Which players does it control?

Anything macOS itself can see. Apple Music and Spotify work, and so does audio or video in a browser tab — YouTube included. Nothing has to be installed in the browser.

Does it send anything anywhere?

No telemetry, analytics or crash reporting. With Currency enabled (the default), Cyclop fetches a public currency list and the selected base currency's rates at startup, then hourly, when the tab opens and when the base changes. It tries cdn.jsdelivr.net and then latest.currency-api.pages.dev, with a 2 MiB response cap. If the normal macOS Now Playing path fails, the Spotify fallback may fetch artwork only from https://i.scdn.co/image/…; redirects are revalidated, responses are capped at 8 MiB and decoded images at 20 million pixels. Providers receive normal HTTPS metadata such as the IP address, request time and requested path; no clipboard, file, note or calendar content is attached.

How is the download verified?

Official releases are Developer ID signed and notarised by Apple. If macOS unexpectedly says one cannot be verified, do not use “Open Anyway”: delete it, download the current image again from the official GitHub releases page, and report a repeatable failure privately. Builds made locally with Scripts/bundle.sh are ad-hoc signed and are not official releases.

What is stored locally?

Clipboard history is memory-only. Snippets, notes, the teleprompter script and settings are unencrypted files under ~/Library/Application Support/Cyclop. The shelf stores absolute paths to original files in app preferences. Clipboard-image saving is opt-in, and an upgrade from a pre-hardening version resets the old value to off once. When enabled, any copied PNG or TIFF is stored in ~/Pictures/Cyclop, subject to size and count limits; the folder is owner-only and saved PNGs use owner-only file permissions. Hide Contents → All replaces every content pane and sensitive header metadata while keeping Settings available; an unreadable configuration fails closed.

What does it cost in memory and battery?

About 40 MB plus a 14 MB helper process, and 0.0 % CPU while the panel is closed. Each tab can be disabled to stop its background service. The calendar clock and player-position ticker also stop when the panel folds.

Which macOS versions are supported?

macOS 15 and newer, on both Apple silicon and Intel. The floor comes from the translation framework the Translate tab uses.

Open source

Cyclop is built in the open under the MIT licence, and a good part of what is in it came from people who turned up in the first week: measurements from Macs the author does not own, a reverse-engineered fix for macOS 26 media control, and fixes to things nobody else had noticed. Issues and pull requests are welcome.
