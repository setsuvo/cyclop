# Cyclop

*[English](README.md) · Русский*

Челка MacBook как рабочий инструмент. Нативное приложение на SwiftUI/AppKit: в покое
невидимо, по наведению мыши разворачивается вниз в панель с плеером, полкой для
файлов, историей буфера обмена и ближайшими встречами.

[![build](https://github.com/akalikbergenov/cyclop/actions/workflows/build.yml/badge.svg)](https://github.com/akalikbergenov/cyclop/actions/workflows/build.yml)
[![Buy Me a Coffee](https://img.shields.io/badge/buy%20me%20a%20coffee-%E2%98%95-FFDD00?style=flat-square&labelColor=000000)](https://buymeacoffee.com/akalikbergenov)

![Панель Cyclop](docs/panel.png)

**[Скачать последнюю версию](https://github.com/akalikbergenov/cyclop/releases/latest)** —
macOS 15 или новее. Официальные релизы подписаны Developer ID и нотаризованы
Apple; обходить Gatekeeper не требуется.

```
0.0 % CPU в покое  ·  ≈40 МБ + 14 МБ helper  ·  4,2 МБ бандл  ·  без запросов разрешений на обычном пути
```

Трек на снимке играет во вкладке браузера — Cyclop читает его из самой macOS, не
требуя ни разрешений, ни настроек в браузере. Как это устроено — ниже.

## Что умеет

| Вкладка | Что делает |
|---|---|
| **Музыка** | Обложка, трек, исполнитель, скраббер с перемоткой, prev / play-pause / next. Источник — **что угодно**: плеер, вкладка браузера, любое приложение, которое видит сама macOS |
| **Полка** | Перетащи файлы в челку — они лежат там, пока не понадобятся; тянешь карточку наружу и файл уходит куда нужно. Клик выбирает карточку, ⌘-клик — несколько, и тогда перетаскивается вся группа. Необязательное сохранение изображений из буфера может положить сюда скопированный PNG или TIFF — в том числе с айфона. По умолчанию оно выключено |
| **Буфер** | История последних 40 копирований, клик возвращает запись в буфер обмена |
| **Заготовки** | Ручной список того, что надоело набирать: почта, телефон, адрес. Добавляются кнопкой прямо в панели, удаляются крестиком на карточке; клик кладёт строку в буфер обмена. Тот же список лежит файлом в `~/Library/Application Support/Cyclop/snippets.json` и правится в редакторе, если так удобнее |
| **Календарь** | Ближайшая встреча на неделю вперёд: сколько до неё осталось, кнопка подключения к Zoom, Meet, Teams и другим. Остальные встречи — списком |
| **Перевод** | Слева пишешь, справа появляется перевод — сам, офлайн, средствами macOS. Английский переводится на русский, русский на английский; направление берётся из письменности. Языковые пакеты macOS не предустанавливает, поэтому первый раз их надо скачать: Системные настройки → Основные → Язык и регион → «Языки перевода…» |
| **Валюта** | Сумма с одной стороны, другая валюта с другой; вводить можно в любое поле. Публичная таблица дневных курсов загружается по HTTPS при запуске и раз в час, пока вкладка включена |
| **Телесуфлёр** | Сценарий ползёт под камерой со скоростью, которую задаёте ползунком. Чёлка — единственное место на экране, которому телесуфлёр правда подходит: читаешь вплотную к объективу, и на записи это выглядит прямым взглядом, а не чтением с экрана. Пока текст идёт, панель держится открытой — сценарий читают, не касаясь трекпада |
| **Заметки** | Временные, в правом столбце иконок: быстро записать, вернуться, удалить или унести через буфер обмена. Наведение сразу даёт каретку, пустые заметки убирают себя сами |

Панель раскрывается по наведению на челку и сворачивается, когда курсор ушел.
Вкладки тоже переключаются наведением — но только если курсор на иконке
задержался: проходящий мимо ничего не переключает.
Во время перетаскивания файлов она раскрывается сама и сразу показывает полку.
Иконка в меню-баре — переключить панель, разом скрыть все вкладки с содержимым
и метаданные в шапке, выйти. Настройки остаются доступны, чтобы режим скрытия
можно было изменить. Саму иконку можно убрать: ⌘-перетащить с бара или переключателем в
настройках; повторный запуск Cyclop возвращает её обратно.

Любую вкладку можно выключить в **Настройках → «Показывать в панели»**.
Выключенная не просто пропадает с рельса — вместе с иконкой останавливается
её фон: опрос буфера, наблюдатель календаря, процесс Now Playing, запрос
курсов. Рельс — для того, куда заглядывают на секунду между делом; редкий
режим на нём не запрещён, но живёт лишь пока тот, кому он не нужен, может
его снять.

## Требования

- macOS 15 или новее (вкладка «Перевод» работает на Translation.framework)
- Swift 6 toolchain (полный Xcode не нужен, хватает Command Line Tools)

На маках без челки приложение тоже работает: панель считает челкой область
180×24 pt по центру верхней кромки экрана.

## Сборка

```bash
git clone https://github.com/akalikbergenov/cyclop.git
cd cyclop
./Scripts/bundle.sh          # swift build + сборка .app + ad-hoc подпись
open build/Cyclop.app
```

Иконка генерируется кодом, без графических редакторов:

```bash
swift Scripts/make-icon.swift "$PWD/Resources/AppIcon.icns"
```

## Установка

Открыть `Cyclop-<версия>.dmg` и перетащить приложение в «Программы».
Открывается с первого раза: с 0.8.0 образ подписан Developer ID и нотаризован
Apple, разрешать и вводить ничего не нужно.

Обновление — тем же способом: открыть новый образ и заменить приложение.
При переходе с версии до 0.8.0 macOS может один раз заново спросить доступ
к календарю: у приложения сменилась подпись, а разрешение было привязано к
ней. Версия видна в меню-баре первой строкой.

Сборка из исходников (`Scripts/bundle.sh`) подписана ad-hoc и не нотаризована,
поэтому отличается от официального релиза. Если macOS неожиданно сообщает, что
официальную загрузку нельзя проверить, не обходите предупреждение. Удалите файл,
заново скачайте актуальный образ со страницы релизов и сообщите о повторяющейся
ошибке через приватный канал из [SECURITY.md](SECURITY.md).

Версии выходят часто, и звезда о них не сообщает — она закладка, а не подписка.
Чтобы узнавать об обновлениях: кнопка **Watch** вверху справа → **Custom** →
галочка **Releases**. Приходить будут только релизы, без обсуждений и правок.

### Собрать образ самому

```bash
./Scripts/dmg.sh
```

Кладет `build/Cyclop-<версия>.dmg` — приложение и ярлык `/Applications` рядом.
Номер версии берется из `Scripts/version`.

### Выпустить версию

```bash
./Scripts/release.sh
```

Проверяет выпуск, ставит тег `v<версия>` и отправляет его на GitHub. Затем
workflow GitHub Actions собирает, подписывает, нотариализует и публикует `.dmg`.
Заметки состоят из двух частей: несколько строк, написанных руками, лежат
в `docs/releases/<версия>.md`, за ними идет список коммитов, который GitHub
собирает сам. Без рукописной части скрипт откажется работать: список коммитов
отвечает на вопрос «что изменилось в коде», а пришедший спрашивает «что мне это
даст» — и второй ответ из первого не получается никаким генератором.

Номер записан **в одном месте** — `Scripts/version`. Оттуда он идет в
`Info.plist` приложения, в имя образа и в тег, поэтому разойтись они не могут.
Поднять версию — это изменить одну строку и запустить скрипт; он откажется
работать, если в дереве есть несохраненное, если коммиты не запушены или если
такой тег уже существует.

Готовые образы лежат на [странице релизов](https://github.com/akalikbergenov/cyclop/releases) —
это и есть ссылка, которую можно давать людям вместо файла.

## Разрешения

**Ни одного при обычной работе** — пока явно не запросишь доступ к Календарю.
Обычный путь Now Playing не просит Автоматизацию или Универсальный доступ, Запись
экрана не используется никогда, а в браузере ничего настраивать не нужно.
Позиция курсора читается через `NSEvent.mouseLocation`, буфер — через публичный
`NSPasteboard`, Now Playing — через helper (см. ниже).

Доступ к Календарю — единственное разрешение на обычном пути. Оно нужно только
вкладке «Календарь», и системный диалог показывается не при запуске и не при
открытии вкладки, а по явному нажатию кнопки на объясняющем экране. Не пользуешься
календарём — обычная работа так и остаётся без разрешений.

Файл, положенный на полку из «Загрузок», «Документов» или с «Рабочего стола», —
единственное, за что macOS спросит отдельно, и спросит в момент открытия полки, а
не при запуске. Отказ ничего не ломает: карточка остаётся, просто без превью.


Разрешения понадобятся только запасному пути, если основной когда-нибудь
перестанет работать: тогда для Apple Music и Spotify будет запрошена
Автоматизация, а медиа-клавишам — Универсальный доступ.

## Приватность и локальные данные

В Cyclop нет телеметрии, аналитики и отправки отчётов о сбоях. Исходящих
сетевых путей два:

- Если вкладка «Валюта» включена (так по умолчанию), при запуске загружаются
  публичный список валют и курсы для выбранной исходной валюты. Затем они
  обновляются раз в час, при открытии вкладки и при смене исходной валюты.
  Сначала Cyclop обращается к `cdn.jsdelivr.net`, затем, при ошибке, к
  `latest.currency-api.pages.dev`. Оператор получает обычные метаданные HTTPS:
  IP-адрес, время и путь запроса; содержимое буфера, файлов, заметок или
  календаря к нему не прикладывается. Ответ ограничен 2 МиБ.
- Если обычный источник Now Playing в macOS не работает и включился запасной
  путь Spotify, Cyclop может скачать обложку по адресу, который вернул Spotify.
  Разрешён только путь `https://i.scdn.co/image/…`, перенаправления проверяются
  повторно, ответ ограничен 8 МиБ и 20 миллионами декодированных пикселей. Сервер
  изображения получает обычные метаданные HTTPS и путь к обложке. На основном
  пути обложку отдаёт macOS, отдельного запроса нет.

История буфера живёт только в памяти, а записи с отметками concealed, transient
или auto-generated игнорируются. Сохранение изображений из буфера требует
явного согласия; обновление с версии до усиления безопасности один раз сбрасывает
старое значение в «выключено», поэтому согласие надо дать заново. Если явно
включить **«Сохранять изображения из буфера»**, любое изображение PNG или TIFF —
не только снимок экрана — преобразуется в PNG,
сохраняется в `~/Pictures/Cyclop` (либо в запасной папке Application Support,
если Pictures создать не удалось) и добавляется на полку. Один файл ограничен
25 МиБ и 40 миллионами пикселей, вся папка — 200 файлами и 512 МиБ. Когда
хранилище достигает лимита, новый файл не сохраняется, а старые не удаляются
автоматически. Очистка в настройках отправляет сохранённые изображения в Корзину.
Папка доступна только владельцу (`0700`), а сохранённые PNG имеют права `0600`.

Постоянный текст Cyclop не шифруется. Заготовки, заметки, сценарий телесуфлёра и
переносимые настройки лежат соответственно в `snippets.json`, `notes.json`,
`teleprompter.txt` и `config.json` внутри
`~/Library/Application Support/Cyclop`. Полка хранит абсолютные пути к исходным
файлам в настройках приложения (`UserDefaults`, ключ `shelf.urls`) и не копирует
файлы, которые на неё перетащили. Папка Application Support доступна только
владельцу (`0700`), а эти файлы имеют права `0600`, но процесс под той же учётной
записью macOS или резервная копия всё равно может их прочитать.

**«Скрывать содержимое → Всё»** закрывает Музыку, Полку, Буфер, Заготовки,
Календарь, Перевод, Валюту, Заметки и Телесуфлёр, включая чувствительные
метаданные в шапке панели. Настройки остаются видимыми. Закрытая панель
заменяется безопасной веткой интерфейса, а не рисуется под блюром или накладкой;
временное раскрытие действует только на том дисплее, где его запросили, и
сбрасывается при сворачивании этой панели. Если `config.json` не
читается, приватность срабатывает безопасно и закрывает все вкладки с
содержимым. При обновлении прежний выбор «всех» четырёх разделов расширяется до
всех девяти вкладок, а неполный выбор остаётся неполным. Это защита для
демонстрации экрана, а не шифрование данных на диске.

Полная опись данных приведена в [SECURITY.md](SECURITY.md).

## Как это устроено

Почему окно именно такое, почему курсор опрашивается таймером, почему
Now Playing живёт внутри `/usr/bin/perl`, во что обходится простой —
восемнадцать записок о решениях, которых по коду не видно:
**[docs/architecture.ru.md](docs/architecture.ru.md)**.

## Ограничения

- Now Playing держится на приватном фреймворке и на том, что `/usr/bin/perl`
  остается платформенным бинарником без library validation. Apple может закрыть
  это в любом обновлении — тогда включится запасной путь с Music и Spotify. По
  той же причине приложение непригодно для App Store.
- Скриптовые рантаймы (включая perl) Apple объявила устаревшими и когда-нибудь
  уберет из системы. Helper переживет это ровно до того момента.
- Полка ссылается на файлы, а не копирует их: если переместить оригинал, карточка
  исчезнет при следующем запуске. Исключение — необязательное сохранение
  изображений из буфера: когда оно включено, любой скопированный PNG или TIFF
  сохраняется в `~/Pictures/Cyclop`. Для папки заданы лимиты по размеру и числу
  файлов; при достижении лимита новый файл не сохраняется. Содержимое удаляет
  только пользователь: очистка в настройках отправляет его в Корзину.
- Записи с типом `org.nspasteboard.ConcealedType` (менеджеры паролей) в историю
  буфера не попадают.
- Кнопка подключения появляется, только если ссылка на созвон есть в самом
  событии — в поле места, в заметках или в URL. Распознаются Meet, Zoom, Teams,
  Webex, Whereby, Jitsi, Телемост и Discord.
- Снимок с айфона приезжает через универсальный буфер обмена, поэтому требует
  того же, что и он: один Apple ID, включённые Bluetooth и Wi-Fi, Handoff и
  устройства рядом. И затирает буфер на маке — затёртое остаётся в истории
  «Буфера» в одном клике.
- Языки перевода macOS не предустанавливает — первый раз пакет придётся скачать
  через Системные настройки; панель говорит об этом и открывает нужный экран.

## Как помочь

Правила короткие и живут в [CONTRIBUTING.md](CONTRIBUTING.md): что принимается,
что нет и что проверить у себя до отправки. Главное правило — приложение
обходится без разрешений macOS и не получает нового сетевого доступа без
отдельного обсуждения безопасности.

О чём приложение читает, что и где хранит, куда ходит по сети — в
[SECURITY.md](SECURITY.md). Там же канал для уязвимостей: приватный, issue
заводить не нужно.
